# Code of Conduct

## Our standard

This project is a professional technical community. Participants are expected to:

- discuss ideas and code with evidence and respect;
- give actionable, specific feedback;
- assume good intent while challenging technical conclusions;
- respect differing experience levels, languages and working styles;
- keep issues focused on reproducible behavior and project scope.

## Unacceptable behavior

- harassment, threats or discriminatory language;
- personal attacks, doxxing or publishing private information;
- deliberate disruption, spam or bad-faith issue filing;
- disclosing another person's credentials or private data;
- pressuring maintainers for unpaid private support.

## Scope

This standard applies in repository issues, pull requests, discussions, review
threads and other project-managed spaces.

## Enforcement

Maintainers may edit, hide or remove content and may restrict participation when
behavior violates this standard. Enforcement decisions should be proportionate,
documented when practical, and focused on restoring a productive environment.
