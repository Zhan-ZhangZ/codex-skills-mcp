# beta.9 搜索历史与长文本搜索修复

日期：2026-10-19。开发版本 `1.5.0-beta.9`，插件 `0.6.0`。本记录不代表 npm 已发布。

## 搜索历史

- 搜索框聚焦且为空时，历史列表以浮层从输入框下方展开，不改变首页布局；历史项逐条淡入下移。默认页面和输入过程中保持收起；失焦后延迟 120ms 收起，保证点击历史项和“更多”时不会被提前关闭。
- 最多保存 8 条非空查询；默认展示最近 6 条，标题旁显示总数，超过 6 条时提供“更多 N / 收起”。
- 历史写入用户级共享文件 `~/.codex-skills-mcp/search-history.json`（可用 `CODEX_SKILLS_SETTINGS_DIR` 覆盖目录），不再按 iframe 或会话隔离。侧边栏、技能托盘和不同 MCP 进程读取同一份记录。
- 共享文件使用进程间锁和原子替换，最多保存 8 条；多个窗口同时记录时按时间合并，不产生重复项。
- 旧版 iframe `localStorage` 记录会在首次连接后按时间顺序导入共享文件，成功后再删除旧副本；导入失败则保留旧副本以便下次重试。
- 15 秒内连续输入会合并为最后一条完整查询，重复查询会移到最前，不产生重复 chip。
- 点击历史 chip 直接重新执行搜索；长查询只显示单行截断标签，完整文本保存在 `title` 和重新搜索参数中。
- 右上角 X 图标清空共享历史，其他会话下次聚焦搜索框时同步为空；面板立即收起。
- 已打开的其他技能托盘在窗口重新获得焦点时主动刷新共享历史，无需重新打开页面。
- 详情页隐藏历史；首页、分类页和搜索结果页都只在搜索框重新获得焦点且内容为空时展示，避免长期占据首页和挤压结果。

## 完整技能带入

- 旧实现只发送“已选择技能 X，请读取资源”的短提示，模型可能跳过读取或只把技能当成普通参考资料。现在详情页在技能完成缓存、完整 `SKILL.md` 加载成功后才启用“带入完整技能”，并把全文放入下一轮模型上下文。加载中按钮保持禁用，处理函数也拒绝提交部分内容；该操作只更新下一轮上下文，不会自动发送消息或触发回复。
- 上下文同时包含技能名称、描述、`skill://` 资源 URI、本地缓存路径、字符数和结构化技能元数据；宿主声明 `resourceLink` 能力时再附带标准资源链接。
- 详情界面最多渲染 20 万字符以保持滚动与 Markdown 渲染流畅，但带入时始终发送完整 `SKILL.md`；上下文块标记为 `audience: ["assistant"]`，避免把大段工作流正文当成用户消息展示。
- `ui/update-model-context` 对同一 App 实例是替换语义。App 会读取 `hostContext["openai/modelContext"]`，把新技能合并到已有上下文；同一技能再次带入只刷新其内容，不会叠加多份全文。
- 宿主移除上下文附件时会发送 `openai/modelContext: null`，App 随之清除“已带入”状态。应用重新挂载时也能回读上次附件，并继续合并。
- 文本块带有 `openai/title`，宿主上下文浮层显示“完整技能：名称”，避免把大段 SKILL.md 当成无标题附件。

### 与原生技能入口的区别

原生 `/skills` 和 `$` 由 Codex 宿主管理，具备按名称、描述进行的隐式选择，并按需加载完整技能。`@Codex Skills` 返回的是 `skill://` 资源链接，模型读取资源后才获得完整说明。

本 App 是显式可视化入口，不能注册成宿主原生系统技能，因此不提供隐式自动选择。当前实现把完整 `SKILL.md` 直接交给下一轮模型，效果比短提示更接近原生选择；依赖脚本和参考文件的技能仍通过资源 URI、`load_skill_file` 和本地路径访问，由模型按说明执行。宿主决定上下文何时进入请求，所以按钮反馈使用“下一轮生效”表述。

## 长文本搜索

搜索页顶部原来显示 `搜索“完整 query”`，复制超长文本后会把页面标题撑开。现在顶部固定显示“搜索结果”，完整 query 只保留在搜索输入框中，结果数量仍在右上角展示。

![长文本搜索结果](benchmarks/app-preview-long-search.jpg)

430px 窄屏下，搜索历史和长 query 输入框都保持单行边界，导航与结果卡片不被挤出视口。

- 全量自动回归 277/277 通过，包含跨进程共享搜索历史、旧版 localStorage 一次性迁移、窗口聚焦刷新、清除、长文本 chip 截断、顶部标题不再重复 query、6 条默认展示与 8 条保存上限，以及加载中禁止提交部分技能、完整技能、超长 SKILL.md、多技能合并、同技能刷新、资源链接和宿主上下文清空。
- `assets/app.html` 与 `plugin/dist/app.html` 已从同一份源码重新构建；`plugin/dist/server.js` 已重新打包。
- 固定宿主 Chrome 预览覆盖桌面历史、长 query 结果页和 430px 历史页，未发现遮挡、溢出或底部错位。
- 当前 Codex 侧边栏连接的是 npm 已发布的 `beta.8`，因此现场仍会显示旧 UI；发布 beta.9 或切换到本地构建并重启 MCP 后才加载本次界面。
