## 成熟实现对照

本阶段保留 MCP SDK 与 OpenAI 扩展作为协议基座，针对实际差异补齐生命周期和业务边界：

- MCP 生命周期与 Streamable HTTP：遵循 initialize/initialized 顺序，失效会话返回协议状态码，处理 Origin、会话关闭及长连接。
- TypeScript SDK：采用 SDK 提供的 HTTP/Express 集成；每个 HTTP 会话保有对应 server/transport，关闭由服务生命周期统一管理。
- OpenAI MCP Extensions 与官方 Bits & Bolts 示例：保留轻量 JSON-RPC transport，由控制器显式完成 UI 握手；同步宿主主题；在卸载时清理请求与监听器；样式和脚本内联到单文件 HTML。
- 分发验收：从生成的 npm 包与插件入口实际完成 stdio 协议工作流，核对资源随包分发，避免仅检查源码编译。

公开官方参考链接见本节后续增补；对应来源由并行参考审计核验。

| p95 | 11.9639 ms | 3.1837 ms | 73.4% |

复现入口为 `scripts/benchmark-search.mjs`；`npm run benchmark` 测当前构建，`--module` 可指定基线导出模块。基准独立于网络，不设依赖机器速度的通过阈值。数值用于比较相同工作负载下的实现差异，不应外推为远程下载或整体任务耗时。
