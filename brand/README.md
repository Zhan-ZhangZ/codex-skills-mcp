# Codex Skills 品牌资源

这里提供商业使用者完成许可证署名所需的官方 Logo、明暗版本和可直接粘贴的声明模板。品牌资产的使用规则以根目录 [LICENSE](../LICENSE) 第 3、4 条为准。

## 文件

| 文件 | 用途 |
|---|---|
| `logo-white.png` | 深色背景、深色主题商品页和插件界面 |
| `logo-black.png` | 浅色背景、白底商品页、README 和文档 |
| `icon-white.svg` | 深色背景的小尺寸图标 |
| `icon-black.svg` | 浅色背景的小尺寸图标 |
| `notice-zh.txt` | 中文商用区分 |
| `notice-en.txt` | 英文商用区分 |
| `attribution-snippet.html` | 可直接放入销售页或“关于”页的 HTML |

Logo 字标原始尺寸为 374 × 120，透明背景。数字销售页面的字标宽度不得小于 160 CSS 像素；“关于/致谢”页不得小于 120 CSS 像素。请只做等比缩放，不要改色、裁切、描边、加特效或拉伸。

## 商用必须出现的位置

1. 每个包含购买或下单入口的销售页面，在商品名称或价格附近。
2. 产品首次运行/引导页。
3. 产品的“关于”“致谢”或“法律”页面。
4. 产品 README 或主要文档。
5. 没有图形界面的产品，还应在帮助/版本输出或对应说明中出现。

只在源码压缩包、依赖文件或许可证弹窗里放 Logo，**不满足**许可证要求。

## 不得这样使用

- 把官方 Logo 当作销售方自己的商标。
- 声称产品是原作者官方发行版，或暗示原作者认证、合作、赞助。
- 改色、裁切、拉伸 Logo，或仅使用局部图形。
- 把 Logo 单独制作成周边、域名、账号头像主要标识或付费素材。
- 用 Logo 掩盖第三方技能、字体、依赖库原有的授权要求。

需要许可证未明确允许的品牌使用方式时，请通过 GitHub 仓库联系维护者。
